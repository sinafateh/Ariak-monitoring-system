# Ariak Monitoring Service

For first administrator setup, account security, and the user/project permission model, see [USER-AUTH.md](./USER-AUTH.md).

این نسخه‌ی اولیه یک پوسته‌ی RTL برای نصاب‌ها و هسته‌ی رابط کاربری مدیریت پنل‌ها را فراهم می‌کند:

- صفحه‌ی پیش‌فرض پروژه‌ها با کارت‌های بزرگ و قابل انتخاب
- نوار اسکرولی پروژه‌ها پس از ورود به یک پروژه
- ستون پنل‌های پروژه در سمت چپ و درخت تنظیمات پنل در کنار آن
- منوی تنظیمات درختی بر اساس بخش ۶ مستندات سیستم
- صفحات نمونه برای System، Loop Card، Group، Features، Events، Remote Panel، Report، GSM و Monitoring
- صفحه‌ی «تاریخ و زمان» با همان تقویم شمسی و انتخابگر ساعت Wheel Picker
- تقویم شمسی با انتخاب روز، جابه‌جایی ماه و دکمه‌ی امروز
- فیلد ساعت جداگانه با فرمت ۲۴ ساعته
- نگه‌داری وضعیت فرم و پیام وضعیت برای اتصال/اعمال روی پنل
- حالت روشن/تاریک با حفظ انتخاب کاربر

اتصال واقعی به پنل، احراز هویت، پروژه‌ها و همگام‌سازی در این مرحله فقط به‌صورت چارچوب و وضعیت نمایشی هستند.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی production:

```bash
npm run build
```
